Pair with FlowSight

Open FlowSight → You → Local automations → Browser pairing. Copy the port and pairing key shown there. The extension talks only to FlowSight on this computer.

In Arc, open arc://extensions, find FlowSight Browser Controls and choose Details → Extension options. After an update, approve any requested site access to enable website blocking.

Open this page from the installed extension's Extension options. Opening options.html directly as a file will not work.
